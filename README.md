# 頭痛ダイアリー Webアプリ

紙の頭痛ダイアリー(坂井文彦先生監修版 `headachediary.pdf`)をもとにした、スマホで記入できるWebアプリです。
**[index.html](index.html) 1ファイルだけで動作**し、サーバーもインストールも不要です。

📖 **スクリーンショット付きの使い方マニュアル: [manual.html](manual.html)**(アプリの設定タブからも開けます)

## 機能

| 紙のダイアリー | このアプリ |
|---|---|
| 頭痛の程度(午前/午後/夜に 十・廾・卅 を手書き) | **時刻を指定して程度(軽度/中程度/重度)を記録すると、0〜24時のタイムラインに自動で線が引かれる**。「治まった」を記録すると線が終わる(未記録なら点線で「継続中」表示) |
| 飲んだ薬の略称・錠数・○△ | 薬の名前(入力履歴からサジェスト)・錠数・効き目(○効いた/△やや/×効かず)を記録。タイムラインにも「薬」マークが付く |
| 影響度(十・廾・卅) | 3段階+「影響なし」をタップで選択 |
| MEMO(タイプ・前ぶれ・誘因など) | 各記録のメモ+日ごとの「原因・きっかけメモ」(自動保存) |
| 生理欄 | なし(不要のため省略) |
| 複写式で医師に渡す | **印刷タブから期間を選んでPDF化**(iPhoneの印刷画面から「PDFとして保存」) |

- データは端末のブラウザ内(localStorage)に保存されます。通信は一切しません。
- 設定タブからJSONで書き出し/読み込みができます(機種変更・バックアップ用)。

## iPhone (Chrome) での使い方

`index.html` はどこかにホスティングする必要があります。おすすめは **GitHub Pages**(無料):

1. GitHubにリポジトリを作成し、`index.html` をpushする
2. リポジトリの Settings → Pages → Branch を `main` にして保存
3. 表示されたURL(`https://<ユーザー名>.github.io/<リポジトリ名>/`)をiPhoneのChromeで開く
4. Chromeのメニュー →「ホーム画面に追加」でアプリのように使える

> 注意: localStorageはブラウザごと・サイトごとに保存されます。いつも同じブラウザ(Chrome)で開いてください。ブラウザのデータを消去すると記録も消えるため、設定タブの「書き出し」で定期的にバックアップしてください。

## PDF化の手順(iPhone Chrome)

1. 「印刷」タブで期間を選ぶ(今月/先月/直近2週間 ボタンあり)
2. 「印刷 / PDFに保存」をタップ
3. iOSの印刷画面でプリンタを選ばずに共有アイコン →「"ファイル"に保存」でPDFになる
   (またはプレビューをピンチアウト → 共有 → PDFとして保存)

## 記号の意味(紙版と同じ)

- 頭痛の程度: **卅**=重度 / **廾**=中程度 / **十**=軽度
- 影響度: **卅**=何も手につかず横になる必要 / **廾**=能率が半分以下 / **十**=大きな支障なし
- 薬の効果: **○**=効いた / **△**=やや効いた / **×**=効かなかった
